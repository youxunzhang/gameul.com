    Game entry builder

    Internal helper for the GameUL team. Capture every field used on site-data.js and grab a ready-to-paste object without digging through previous entries.

    How to use this helper

    1. Fill out every field below. Use the “Add another” buttons to add as many categories, screenshots or other list items as needed.
    2. Watch the live JSON preview update as you type. Fix any validation notes (slug pattern, duplicate slug, rating range, URL format) before copying.
    3. Click Copy snippet to place the object on your clipboard, then paste it inside the const games = [] array in assets/js/site-data.js.
    4. Duplicate an existing detail page, rename it to games/<slug>/index.html, and update the screenshots, copy and embed.

    Tip: recommended slugs should point to existing entries so the “You may also like” list stays accurate.
