About This Game

Puffer Party is a multiplayer category game by Krillion. Players take turns naming an answer that fits the prompt, then pass the puffer before it pops. Gameul lists the title and links to the official Krillion website, where the game runs.

How to Play

  1. Open Puffer Party on the official Krillion website.
  2. Create a room for friends or join an available public room.
  3. When it is your turn, enter a valid answer for the category and pass the puffer before it pops.

Controls

  • Open the official Krillion game page
  • Create a private room or join a public room
  • Enter an answer, submit it and pass the puffer before time runs out

Tips and Strategies

  • Think of a few possible answers while other players take their turns.
  • Submit a clear, correctly spelled answer to avoid losing time.
  • Use a private room when you want to play with a specific group of friends.

Frequently Asked Questions

Can I play Puffer Party directly on Gameul?

No. Krillion only allows the game to run on its own website, so the Play on Krillion button opens the official game page.

Is Puffer Party multiplayer?

Yes. Krillion describes it as a multiplayer category game that supports playing with friends or joining a public room.
