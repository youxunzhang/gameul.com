    How to update the list

    The grid above reads straight from assets/data/games-directory.json. To add, edit or remove games:

    1. Open the JSON file and duplicate an entry inside the games array.
    2. Update the title, URLs, categories, tags and image path for your new game.
    3. Save the file — the directory will refresh automatically the next time the page loads.

    You can also bookmark the JSON link above for a quick editing shortcut.
