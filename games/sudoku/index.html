About This Game

Sudoku is a number-placement logic puzzle. The goal is to complete the grid so every row, column and three-by-three box contains the digits 1 through 9 exactly once.

How to Play

  1. Choose a difficulty and inspect the given numbers.
  2. Enter one digit from 1 to 9 in each empty cell.
  3. Complete every row, column and box without repeating a digit.

Controls

  • Select an empty cell and enter 1–9
  • Use Check to highlight mistakes
  • Use Hint when you need one answer

Tips and Strategies

  • Look for rows, columns or boxes with only one missing number.
  • Use elimination before making a guess.
  • Recheck a number against all three constraints: row, column and box.

Frequently Asked Questions

Do I need to be good at maths?

No. Sudoku uses logic rather than arithmetic; the numbers work as nine distinct symbols.

Are hints required?

No. Hints are optional and reveal one correct value when requested.
